# Stage C — The Last Slice

The story is defined in `stories/the_last_slice.json`: title, duration, actors and costume identity, set, props, shot ranges and camera transforms, expression and head-turn tracks, action timings, caption slots and sound-effect cues. `scripts/render_story.py` interprets this schema using the existing café and R6 assets. Its interaction driver is a reusable two-actor plate-reach/launch/head-landing template; a different action type requires a new driver, not a new camera, caption or edit engine.

## Local preview

```sh
blender -b --python-exit-code 1 --python scripts/render_story.py -- --story stories/the_last_slice.json --profile preview --output render/story
python3 scripts/edit_story.py --story stories/the_last_slice.json --profile preview --frames render/story --output render/final --verify-slot
```

## Full quality (1080×1920, 24 fps, 64 Cycles samples)

```sh
blender -b --python-exit-code 1 --python scripts/render_story.py -- --story stories/the_last_slice.json --profile full --output render/story-full
python3 scripts/edit_story.py --story stories/the_last_slice.json --profile full --frames render/story-full --output render/final-full --verify-slot
```

Requires Blender 4.0+ (CPU Cycles), Python 3, FFmpeg with libass, and DejaVu Sans Bold. No external visual assets, music, or paid service. GitHub Actions → Stage C story short → Run workflow → profile=preview or full. CI renders four parallel shot ranges of one identical timeline, checks manifests agree and frames are contiguous, then assembles and edits. The final file is `the_last_slice.mp4`.

## Narration slot

The shipped video is captioned with music/SFX only. To insert a take, use the same edit command and append `--narration /path/to/voice.wav`. The narration is mixed at unity gain; the music bed is reduced to 28%, SFX retained, and the final mix is limited only to prevent clipping. The optional test uses a temporary synthetic tone and verifies the alternate mix, but does not include that tone in the artifact.

Captions are one word at a time, bold white with black outline, bottom-centre; slots are distributed evenly and quantized to frame boundaries. Original warm instrumental and four synthetic SFX are generated by standard-library Python. The output includes music, SFX and mix WAVs, ASS captions, word timing JSON, scene manifest, story spec, Blender file and ffprobe metadata.

The plate uses a real grip socket and supported skid; the cake has a continuous ballistic flight with a supported landing on the lead's hair. This is an authored gag, not general collision physics. The approved A2/B code is not modified.
